def calcula_media(x, y):
resultado = (x + y) / 2
return resultado
En programa.py:
a = 3
b = 5
print("La media de ", a, " y ", b, " es: ", calcula_media(a, b))
Se pasan los valores:
a = 3  x = 3
b = 5  y = 5
Entonces:
(3 + 5) / 2 = 4.0
Y se imprime:
La media de 3 y 5 es: 4.0
Respuesta final
La unica opcion correcta es la Opcion 3.
La idea fundamental es: las variables a y b de programa.py 
no se pueden usar directamente dentro de una funcion definida en 
otro modulo. Para llevar esos valores a la funcion, se deben pasar
como parametros, como se hace con x e y en la Opcion 3.
